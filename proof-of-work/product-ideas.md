# Product ideas — pick and ship

Build products, not tutorials. Pick 3–5 over the roadmap; each must hit the bar in
[`README.md`](README.md) (auth, payments, real AI workflows, deployment, monitoring, analytics,
background jobs, real DB, polished UI, docs).

| Idea | Core AI workflow | Why it's a good showcase |
|---|---|---|
| AI research assistant | RAG over a corpus + multi‑step agent + citations | Shows retrieval quality, grounding, eval discipline |
| AI coding platform | Repo indexing, tool‑calling agent, sandboxed execution | Shows agent reliability, sandboxing, streaming UI |
| AI CRM | Enrichment agents, email drafting, pipeline summarization | Shows integrations, background jobs, multi‑tenancy |
| AI meeting assistant | Audio pipeline (STT), summarization, action‑item extraction | Shows multimodal + async processing |
| AI recruiter | Resume parsing (OCR), structured extraction, ranking + evals | Shows structured output + evaluation |
| AI finance dashboard | Doc ingestion, structured extraction, RAG Q&A, charts | Shows data pipelines + trustworthy output |
| AI customer support | RAG knowledge base, escalation to human‑in‑the‑loop, feedback loop | Shows HITL, online eval, retention metrics |
| AI browser agent | Planning, tool use, DOM actions, guardrails | Shows agent orchestration + safety |
| AI automation platform | User‑defined workflows, triggers, agent steps, retries | Shows queues, event‑driven design, reliability |
| AI content system | Briefs → drafts → edits pipeline, brand voice, review queue | Shows prompt engineering + workflow design |

## Selection notes

- Prefer ideas that let you reuse `projects/07–11` rather than starting cold.
- One should be **your Leora backend** (`projects/11`) — the integrated capstone.
- Each idea needs a one‑line "riskiest assumption" before you start (see `08-product-and-people/00-product-thinking/mvp.md`).
